# BRUTAL TODO

Брутальный, жесткий и бескомпромиссный менеджер задач. Никакого визуального мусора — только ты и твои цели. Меньше слов, больше дел.

**[Посмотреть живой проект](https://1-oleks-iv.github.io/BRUTAL-TODO/)**

## Фичи
- **Умная авторизация:** Безопасный вход и защита маршрутов.
- **Облачная синхронизация:** Задачи хранятся в Firebase Cloud Firestore. Доступ с любого устройства.
- **Брутальный UI:** Уникальный дизайн в стиле необрутализма, CSS-анимации и кастомные UI-компоненты.
- **Управление задачами:** Создание, удаление, редактирование, изменение приоритета и отслеживание статуса (Active / Completed).

## Технологии
- **Frontend:** React, React Router, React-Bootstrap
- **Backend/DB:** Firebase (Authentication, Cloud Firestore)
- **Сборка и Деплой:** Create React App, GitHub Pages

## Как запустить локально
1. Клонируй репозиторий: `git clone https://github.com/1-oleks-iv/BRUTAL-TODO.git`
2. Установи зависимости: `npm install`
3. Создай проект в Firebase и добавь свои ключи в `src/firebase.js`
4. Запусти сервер разработки: `npm start`
